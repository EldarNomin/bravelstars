# Формат карты

Файл `data/maps/<id>.json`. Пример: `data/maps/_debug_arena.json`.

```json
{
 "name": "Название карты",
 "mode": "gems",
 "author": "glm",
 "grid": [
  "XXXXXXX",
  "X1.*.2X",
  "XXXXXXX"
 ]
}
```

Все строки `grid` одной длины. Одна клетка = одна единица расстояния в симуляции (ширина героя ~0.8 клетки).

| Символ | Клетка |
|---|---|
| `.` | пол |
| `#` | стена, ломается суперами с `breaks_walls` |
| `X` | непробиваемая стена (края карты, ключевые укрытия) |
| `*` | куст: прячет героя, не мешает движению и выстрелам, ломается как стена |
| `~` | вода: нельзя пройти, можно простреливать |
| `1`…`9` | точка появления команды 1…9 (пол под ней) |
| другие буквы | метки режима, пол под ними. `G` — шахта кристаллов, `B` — ящик с усилителем (будут в G-02/G-03) |

## Правила хороших карт

- Карта симметрична для команд (зеркально или поворотом на 180°).
- Края — сплошной `X`.
- Размер для 3v3: около 21×33 (ширина × длина вдоль линии между базами); для отладки можно меньше.
- От точки появления до врага не должно быть прямой простреливаемой линии длиннее 10 клеток.
- Кусты — группами от 2×2, чтобы в них было где прятаться.

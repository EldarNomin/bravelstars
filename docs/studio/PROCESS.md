# Как работает студия

## Состав

| Кто | Роль в студии | Обязательные действия |
|---|---|---|
| **Владелец** | продюсер и геймдизайнер, финальное слово | утверждает задачи недели, мержит, играет на телефоне, решает на гейтах |
| **Claude** | технический директор и лид-инженер | ядро, бой, сеть, ИИ ботов (каркас); ревью всех PR; ведёт `TASKS.md`; пишет промпты задач остальным; разбирает плейтесты |
| **Codex** | инфраструктура, QA-инженерия и **3D-моделирование** | CI, сборки, тесты, сервер, деплой, метрики матчей; 3D-модели героев, окружения и снарядов, скелеты и анимации — скриптами Blender (`tools/blender/`), экспорт в glTF |
| **Antigravity** | всё, что видит игрок на экране, + «QA-глаз» | стиль игры (`STYLE.md`), UI, управление, камера, VFX, материалы и текстуры, иконки; вставляет модели Codex в сцену; прогоняет сцены и прикладывает скриншоты/видео |
| **GLM** | контент по шаблонам | герои, карты, тюнинг ботов, тексты |

Советники (независимые агенты Claude: геймдиректор, техлид, продюсер) собираются на ревью перед каждым гейтом и по крупным PR ядра.

## Ритм недели

| Когда | Что | Время владельца |
|---|---|---|
| **Пн** | Claude предлагает 3–5 задач недели и промпты к ним; владелец утверждает | 15 мин |
| **Будни** | агенты работают асинхронно; Claude ревьюит PR в течение суток и ставит метку `ready-to-merge` | раз в 1–2 дня: пакетный мерж, ~5 мин |
| **Сб, «вечер сборки»** | мерж всего готового → APK из Actions на телефон → 20 мин игры → заметки в `docs/playtest/ГГГГ-ММ-ДД.md` по шаблону | 1–1.5 ч |
| **Вс** | Claude разбирает заметки: баги в Issues с приоритетом P0–P2, задачи на следующую неделю | — |
| **Гейт вехи** | ревью советников + решение владельца, запись в журнал `PLAN.md` | 30 мин |

## Поток задачи

1. Claude готовит промпт по шаблону `docs/studio/TASK_PROMPT.md` и ставит задаче статус `ready` в `TASKS.md`.
2. Владелец вставляет промпт агенту (Codex / Antigravity / GLM).
3. Агент: ветка `<агент>/<ID>-кратко` от свежего `main` → работа → ребейз → PR `<ID>: название`.
4. CI зелёный → ревью Claude по чек-листу ниже → метка `ready-to-merge` или замечания в PR.
5. Владелец мержит пачку. Статусы в `TASKS.md` обновляет только Claude (иначе конфликты в каждом PR).

## Чек-лист ревью

- [ ] Выполнен «Готово, когда» из `TASKS.md`
- [ ] PR ≤ ~400 строк кода (данные и ассеты не считаются)
- [ ] Только свои папки (см. `AGENTS.md`), `project.godot` не тронут без согласования
- [ ] `src/sim`: нет `Input`, `Time`, `randf()`, узлов; ресурсы `*Data` не изменяются; события через `emit`
- [ ] Числа баланса — в `data/`
- [ ] Есть тесты на логику; для визуала — скриншот или видео с телефона
- [ ] Нет чужого IP

## Приоритеты багов

- **P0** — падение, не собирается, не ставится, матч не доигрывается. Чиним до новых фич.
- **P1** — мешает играть или ломает баланс. В ближайший спринт.
- **P2** — косметика. Когда будет время.

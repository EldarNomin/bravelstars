# Проверка переноса на Unity — 2026-11-08

Перенос реализован и локально проверен. **Приёмка на физическом Android ещё не
пройдена:** `adb devices` не обнаружил устройство. Проект нельзя считать прошедшим
мобильный гейт VS0 только по результатам ПК и сборки APK.

Исходная версия: `origin/dev`, `dfd3bc9`. Unity **6000.3.25f1 / e1dba0a9aba4**,
Windows, установленный Android Build Support с OpenJDK/SDK/NDK. Перенос включает
только реализованное в этой версии: три героя, четыре карты, два режима, боты,
разрушение/отрастание, лобби, HUD, результат, модели/анимации. Будущие задачи сети,
VFX/звука и меты из Godot-плана не объявляются выполненными этим переносом.

Скриншоты получены явным рендером камеры и uGUI в RenderTexture: скрытое окно
Windows не предоставляет надёжный кадр swapchain. Проверка отвергает пустой
кадр. Это изображения Unity player, а не рисунки или рендеры Blender.

Исправленные при проверке дефекты: экспорт служебных сфер костей, отсутствие
animation takes в первом FBX, неверное преобразование цветов linear→sRGB,
вода под полом, герой под левым стиком у появления, обрезанные описания на 4:3,
старый счёт/текст возрождения под экраном результата.

## APK

- Файл: `unity/Builds/Android/bravelstars-unity-debug.apk` (игнорируется Git).
- Размер: **41 830 212 байт** (~39.9 MiB).
- SHA256: `d89ea5efd74c12cd3616fb10050dd441d2eae61a2af454ad7e409a1852b4ce1b`.
- App ID: `com.bravel.arena.unity`, версия 0.1.0, code 1; отдельный от Godot.
- Только `arm64-v8a`; `libil2cpp.so` присутствует. Все ELF LOAD-сегменты имеют
  alignment 16384; ZIP alignment и APK signature verification прошли.
- Development APK содержит разрешение INTERNET, необходимое инструментам Unity
  для отладки; рекламные и аналитические SDK не добавлены.

Android настроен с [optimized frame pacing](https://docs.unity.com/en-us/engine/6000.3/script-reference/unityeditor/playersettings/android/optimizedframepacing),
а UI использует [Screen.safeArea](https://docs.unity.com/en-us/engine/6000.3/script-reference/unityengine/screen/safearea).
Режимы 30/60 FPS — ограничения частоты и разрешения, не измерение достигнутого FPS.

## Повторить локально

```powershell
powershell -ExecutionPolicy Bypass -File tools/unity/verify.ps1 -WithAndroid
python tools/unity/verify_apk.py unity/Builds/Android/bravelstars-unity-debug.apk --output artifacts/unity/apk.json
```

Логи: `artifacts/unity/windows-build.log`, `android-build.log` и `*/player.log`.
В каждом каталоге разрешения есть `runtime.txt` с `RUNTIME_SMOKE_PASSED` и PNG.
GitHub workflow `Unity portable core` проверяет переносимость C# и соответствие
данных/моделей; Unity/Android CI без отдельной настройки лицензии не добавлен.

## Осталось для мобильной приёмки

Установить этот APK на ARM64 Android 8+; сыграть несколько полных матчей каждым
героем, одновременно бегать/целиться/стрелять, свернуть и вернуть игру, проверить
края/вырезы и обе landscape-ориентации. На недорогом устройстве измерить FPS,
память и нагрев после 10–15 минут: ≥30 FPS в режиме экономии, отсутствие падений
и роста памяти между матчами. Эти пункты пока **не проверены**.
